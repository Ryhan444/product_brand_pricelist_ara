This module extends the OCA product_brand functionality. It introduces a new option: Applied on Product Brand in Pricelists.

With this feature, pricelists can be applied based on the selected Product Brand, making it easier to manage brand-based pricing in both Sales and Point of Sale.

Key Features:

  • Adds "Product Brand" option to Pricelist rules.
  • Supports brand-based filtering in Sales Orders.
  • Works with Point of Sale pricelist application.
